## 一句话结论

**有条件推荐**：可做知识库检索问答底座；权限、审计、信创需二次开发（或采购企业版），交付前需完成 License 与安全整改，并锁定版本。

## 待确认清单

| 事项 | 为什么没能确认 | 建议验证方式 |
|---|---|---|
| 实际运行效果 | 本次环境低于官方最低配置，且拉不到镜像 | 在 ≥ 4 核 16 GB 的 x86 机器上按官方 compose 部署，跑通「建库 → 上传 → 解析 → 问答」 |
| 完全离线是否无外联 | 静态分析只能找到已知外联点，找不全 | 断网环境端到端冒烟 + 抓包 |
| ARM（鲲鹏、飞腾）自建镜像 | 官方不出 ARM 镜像，未实际构建 | 在目标机型上构建 Python 后端镜像并跑全链路 |
| 金仓 PG 兼容模式能否直接用 | 代码支持 PostgreSQL，未连金仓实例 | `DB_TYPE=postgres` 指向金仓实例，跑初始化与回归 |
| 检索性能与并发 | 无法从代码确认 | 用客户真实数据规模压测 |
| Python 依赖协议 | `uv.lock` 不带协议字段 | 逐包复核 extract-msg、pcodedmp、rtfde、demjson3 等 |
