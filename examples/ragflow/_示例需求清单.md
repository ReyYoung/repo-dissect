# 示例需求清单：央国企企业知识库平台（技术部分）

> 用途：验证 repo-dissect 的需求响应矩阵（Q 层）。按央国企企业知识库项目的常见要求拟定，非真实招标文件。

## 一、知识采集与治理
1.1 支持 PDF、Word、Excel、PPT、TXT、HTML 及扫描件（OCR）等常见格式文档的上传与解析。
1.2 能识别文档中的表格、标题层级和版面结构，解析结果可人工校对修正。
1.3 支持对接现有业务系统（如 OA、文档管理系统、数据库）自动同步知识，支持定时增量更新。
1.4 支持知识的标签、元数据管理，可按部门、业务域分类。
1.5 支持知识库内容的版本管理与变更追溯。

## 二、智能问答与检索
2.1 支持自然语言多轮问答，答案标注出处并可定位到原文。
2.2 支持全文检索与语义检索混合，检索结果可按元数据过滤。
2.3 支持面向不同业务场景配置多个问答助手（不同知识范围、提示词）。
2.4 支持智能体 / 工作流编排，实现业务流程类应用。
2.5 支持问答结果的满意度反馈与统计分析。

## 三、权限与安全
3.1 支持与企业统一身份认证对接（LDAP/AD、CAS 或 SAML 单点登录）。
3.2 支持基于角色的权限控制（RBAC），可细化到知识库、文档级别，问答结果按用户权限过滤。
3.3 具备完整的操作审计日志（登录、查询、下载、配置变更），可查询导出，留存不少于 6 个月。
3.4 支持敏感词过滤与内容安全审核。
3.5 传输加密（HTTPS），敏感数据存储加密，支持国密算法。

## 四、部署与运维
4.1 支持完全内网私有化部署，运行时不依赖外部互联网。
4.2 支持接入本地部署的国产大模型（如 DeepSeek、通义千问私有化版本）。
4.3 支持信创环境：国产 CPU（鲲鹏 / 飞腾 / 海光）、国产操作系统（麒麟 / 统信）、国产数据库（达梦 / 人大金仓 / GaussDB / OceanBase）。
4.4 支持集群化部署与水平扩展，关键组件高可用。
4.5 提供系统运行监控（服务状态、资源使用、调用量统计）。
4.6 支持数据备份与恢复，版本升级平滑迁移。

## 五、开放与集成
5.1 提供标准 RESTful API，便于业务系统集成。
5.2 支持将问答能力嵌入门户网站、企业微信、钉钉等渠道。

## 六、性能
6.1 千万级文档切片规模下，检索响应时间不超过 3 秒。
6.2 支持 500 个并发用户同时问答。
